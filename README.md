# PIECER

Kerangka proyek Android native untuk **PIECER** (Kotlin + Jetpack Compose + Material 3).

## Versi yang Digunakan

| Komponen | Versi |
| --- | --- |
| JDK | 21 (Temurin 21.0.11) |
| Gradle | 8.14.3 |
| Android Gradle Plugin (AGP) | 8.5.2 |
| Kotlin | 2.0.21 |
| Compose Compiler Plugin | 2.0.21 (`org.jetbrains.kotlin.plugin.compose`) |
| Compose BOM | 2024.09.03 |
| `minSdk` / `compileSdk` / `targetSdk` | 26 / 34 / 34 |

## Build

```bash
./gradlew assembleDebug
./gradlew installDebug
```
